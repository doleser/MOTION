# Motion

Motion is a mobile application designed to make playing sports like basketball easier, connecting users in-person and on their own terms.

### Features

Discover playing courts in your area and view recent activity.

Play on your own terms, deciding where and when using Motion's analytics.

Connect with other users to coordinate times and establish regular meets.

## Installation

Use the package manager [pip](https://pip.pypa.io/en/stable/) to install Motion.

```bash
pip install motion
```
