#### Progress and issues

- **CI and database tests (PR #5).** Built the GitHub Actions workflow (app and database
  jobs) and 25 pgTAP tests for profiles and courts.
- **Migration 2 (PR #8):**
  - sign-up profile columns
  - `complete_profile`, which sets the starting Elo (400/800/1200) once per user
  - `is_username_available`, which works signed out
  - 22 tests
- **Migration 3 (PR #10): the `check_ins` table.**
  - one open check-in per user
  - check-ins expire after 3 hours
  - no direct client writes
  - only players checked in at a court can see who is there
  - Realtime turned on
  - 21 tests
- **Migration 4 (PR #11): `nearby_courts(lat, lng, radius)`.**
  - returns player count, average Elo, and distance, closest first
  - callable signed out
  - radius capped at 50 km
  - 9 tests
- **Deployed migrations 2–4 to hosted Supabase.** All 77 pgTAP tests pass in CI.
- **Learned:**
  - A row-level security policy can't query its own table, because it recurses forever.
    Moved that check into a small `security definer` function.
  - A partial unique index can't use `now()`, so an expired check-in still blocks the next
    one. `check_in` has to close it first.
  - Realtime change events follow RLS, so they can't keep public map counts live. For the
    Beta, the map re-fetches instead.
- **Issues:**
  - The living doc sync brought back errors I had fixed. They need fixing in the Google Doc
    itself.
  - The Denny Courts and IMA locations aren't verified on site yet.
